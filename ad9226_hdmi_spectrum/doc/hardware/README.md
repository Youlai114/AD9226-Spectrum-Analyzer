# 硬件设计文件归档

本目录用于归档与固件配套的**硬件设计文件**。当前状态：硬件已由原作者完成并理论验证，
设计文件**待归档**（接到本目录后请提交入库）。

## 应归档的内容

| 文件 | 格式建议 |
|---|---|
| 载板原理图 | PDF（含版本号与日期页）|
| 载板 PCB 工程 | Gerber 包 + 源文件（立创EDA/AD 工程 zip）|
| 抗混叠滤波小卡（如有） | 原理图 PDF + Gerber |
| BOM 表 | CSV（含器件型号、厂商、数量）|
| 实物照片 | 装配完成后的正反面照片 |

## 规范

1. 命名：`hw_v<主.次>_<日期>_<内容>`，例如 `hw_v1.0_20251101_载板原理图.pdf`；
2. **固件版本与硬件版本必须配对记录**：固件版本见根目录 `VERSION` 与 `CHANGELOG.md`；
   硬件改动（如换排针、改电源）后须在 `CHANGELOG.md` 追加条目并重新回归；
3. 引脚定义以 `../doc/引脚对照与约束.md` 为唯一基准，原理图改动后须回核该表。
