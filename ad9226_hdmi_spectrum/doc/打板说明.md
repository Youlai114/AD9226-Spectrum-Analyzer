# 打板说明（Tang Nano 20K 载板 + AD9226 + 人机界面）

目标：做一块底板，把 **Tang Nano 20K**（插在两排 2×10 排针上）、**AD9226 模块**、
**EC11 旋转编码器**、**5 个按键**、**2 个指示灯** 装到一起，SMA 进、HDMI 出。

> 电气上唯一"必须精确"的是下面第 1 节的引脚表；第 2 节之后是画板时的注意事项。
> 打板前请先看第 7 节的"三件必须实测的事"。

### 1.1b AD9226 模块 P2 丝印映射（按实物丝印，已飞线实测验证）

底板上给模块的插座（原理图里的 H1）是 **2×10 双排**，
下表按模块 P2 排针的实际丝印 1:1 记录，**照这个画，插上就能对上**：

| P2 脚 | 网络 | P2 脚 | 网络 |
|---|---|---|---|
| 1 | +5V | 2 | +5V |
| 3 | GND | 4 | GND |
| 5 | D0 | 6 | CLK |
| 7 | D2 | 8 | D1 |
| 9 | D4 | 10 | D3 |
| 11 | D6 | 12 | D5 |
| 13 | D8 | 14 | D7 |
| 15 | D10 | 16 | D9 |
| 17 | OTR | 18 | D11 |
| 19 | GND | 20 | GND |

注意两点：

1. **数据线是"奇偶交错"的**（5=D0、7=D2、9=D4… 配 8=D1、10=D3、12=D5…），
   不是 5=D0、6=D1、7=D2 顺着排。画封装时最容易在这里想当然。
2. **这份映射以模块实物丝印为准**。换批次/换厂家可能不一样，
   拿新模块前先用万用表量一遍（P2 某脚 ↔ AD9226 芯片 13 脚 = D0、1 脚 = CLK）。
   该映射已在本工程的飞线阶段实测通过（音频信号测频准确）。

### 1.2 为什么是这几个（不能动的部分）

- **76 是 `GCLKC_1`**：全局时钟专用输出脚，54 MHz 从这走时钟网络，不要换。
- **77 是 `GCLKT_1`**（时钟输入脚），本工程当 D3 用，可以换但没必要。
- 以下脚**绝对不能用**：`54 / 55 / 56`（SSPI 专用，布线会被拒）、
  `80 / 85`（Flash D2/D1）、`79`（WS2812）、`51`（功放使能）、`52 / 53`（HDMI EDID）。
- 剩下的 10 个可用 IO 已被"5 键 + 编码器 3 线 + 2 灯"用满，**没有余量了**。
  如果还要加按键，只能共用编码器 A/B 做按键矩阵，或者在软件上做"长按 = 第二功能"。

## 2. 每个信号的外部电路

### 2.1 按键（KEY1~KEY5，低有效）

```
        3V3 ──[10k]──┬──── FPGA 引脚
                     │
                   [ C ]   ← 焊盘留出来, 默认不焊
                     │
                    GND
        FPGA 引脚 ──┬── 轻触开关 ── GND
```

- 必须**外部 10k 上拉**：FPGA 内部上拉只有几十 kΩ，抗干扰不够；
  而且 FPGA 未配置时引脚是浮空的。
- **电容留焊盘、默认不装**（见 2.4 为什么）。
- 5 个按键的接法完全一样。

### 2.2 EC11 旋转编码器

```
        3V3 ──[10k]──┬── A 相 ── FPGA 48
                     ├──[ C ]── GND    ← 焊盘留出来, 默认不焊
        3V3 ──[10k]──┬── B 相 ── FPGA 49
                     ├──[ C ]── GND    ← 同上
        C (公共端) ──────────────── GND
        SW 一端 ─────────────────── GND
        SW 另一端 ──┬── FPGA 72
                    └──[10k]── 3V3
```

- **C 是公共端，接 GND**，不是信号相。如果你的编码器是 5 脚
  （A/B/C/SW/SW），就是上面这种接法。
- **A/B 的顺序各家不同**：画封装前用万用表量一下（慢慢转，看先通的是哪两个脚），
  接反了只会左右方向相反，软件里调 `key_enc_ctrl.v` 的 `e_up/e_dn` 即可。
- 上拉**靠近编码器**放，不要放在 FPGA 端。

**上拉是必须的，电容不用装。** EC11 的 A/B 是"机械触点接地"，
触点本身不产生电平 —— 没有上拉就是悬空，读不到任何东西。

电容的取舍见 2.4：**默认不焊，只在焊盘上留位置**。

### 2.3 LED（低电平点亮，与板载 LED 同极性）

```
        3V3 ──[1k]── |>| ──── FPGA 引脚
                     LED
```

- **接 3V3，不是接 GND**：阳极经电阻接 3V3，阴极接引脚，引脚输出 0 → 亮。
  这样才和板载 LED 同极性（板载 6 只也是低电平点亮）。
- 限流电阻 **470 Ω ~ 1 kΩ**：3.3V − Vf(红 1.8V / 绿 2.1V) ≈ 1.2~1.5 V，
  R=1k 时约 1.5 mA，R=470Ω 时约 3 mA，都够亮。取 1k 更省电。
- 板载的 6 只 LED 仍然连着 15~20，**其中 15~19 现在被按键占用**：
  按键按下时会把引脚拉低，板载 LED 会跟着亮 —— 这是正常的"按键反馈"，不用管。
- **20 脚（LED_STAT）上会并联板载 LED5 和底板 LED**，两个一起亮/灭，
  总灌电流约 3 mA，远小于 `DRIVE=8 mA`，安全。
- 如果非要改成高电平点亮（引脚→电阻→LED→GND），把 `video_top.v` 里
  `assign O_led[0] = ~heartbeat;` 的 `~` 去掉即可（两行都要改）。

### 2.4 AD9226 的 14 根线

- 数据线 D0~D11：直连，**每条线串 22~33 Ω**（靠近 FPGA 端）压过冲，可选但推荐。
- **CLK（76 → 模块 CLK）必须串 33 Ω**，并且**这条线两侧包地**，长度尽量短。
- 54 MHz 下这些措施比画得漂亮更重要。

---

### 2.5 到底要不要加消抖电容：不加（留焊盘即可）

**结论：按键和编码器的电容都不装，PCB 上留焊盘（0603）备用。**

三个理由：

1. **软件已经把这件事干完了，而且更准。**
   - 按键：1 ms 采样 × 8 次一致才认 → 8 ms 消抖
   - 编码器：0.5 ms 采样 + 4 状态格雷码 + 净计数（抖动是 +1/-1 交替，自己抵消）
   仿真里 9 项检查全过（`tb_key_enc`），包括抖动和快速旋转。

2. **加电容在 FPGA 上反而可能更糟。** 普通 LVCMOS 输入没有施密特触发器，
   边沿被 RC 拖慢后会在阈值附近停留更久，这段时间里任何噪声都会造成**多次翻转**。
   RC 消抖是给 51/STM32 那种带施密特输入的 MCU 用的，FPGA 这边不划算。

3. **编码器的 RC 有硬上限。** 10k×100nF = 1 ms，而 EC11 每个电气状态只持续
   1~2.5 ms（20 定位/圈，手快转 5~10 圈/秒）。边沿稳定到 95% 要 3RC ≈ 3 ms，
   比状态还宽 → **会漏格、甚至判错方向**。要装也只能装 10nF（RC=0.1 ms），
   而 10nF 对抑制干扰几乎没用，属于白装。

**什么情况下才需要补焊：**

| 场景 | 焊多大 |
|---|---|
| 编码器/按键的线拉到面板，长度 > 20~30 cm | 编码器 10nF、按键 100nF |
| 板子旁边有继电器、电机、开关电源 | 同上，并把上拉从 10k 降到 4.7k |
| 桌面短排线、干净电源（你的情况） | **不焊** |

**想更抗干扰，改软件比加电容好**（不用改板）：

- 按键：`key_enc_ctrl.v` 里 `k_cnt == 3'd7` 改成 `3'd15` → 消抖从 8 ms 变 16 ms
- 编码器：`TICK_N`（0.5 ms 基准）改大 → 采样变慢，抗毛刺更强，但快速旋转会跟不上

## 3. 电源

```
DC 5V 输入 ──┬──[磁珠/π 滤波]──┬── AD9226 模块 5V
             │                 └──[SS14 或跳线]── Nano 20K 的 5V 脚
             └── GND
Nano 3V3 ──── 上拉电阻 / LED 限流（< 50 mA）
```

**关键：Nano 的 5V 排针直接连 USB VBUS。**
如果底板 5V 和 USB 同时接，会互相倒灌。做法二选一：

- 底板 5V 到 Nano 之间串一个 **SS14 肖特基**（压降 0.3 V，Nano 侧约 4.7 V，够用）；
- 或者串一个**跳线帽**，调试时用 USB 供电、跳线拔掉；正常运行时插跳线、USB 只留数据。

AD9226 模块的 5V 单独走一路 π 滤波（磁珠 + 10µF + 100nF），
**不要**和 Nano 的数字 5V 共用一段走线，否则 HDMI 的开关噪声会进模拟前端。

## 4. 抗混叠滤波器（打板的最大价值，建议留焊盘）

之前只能靠飞线，没有模拟低通，带外强信号会折叠进 0~1 MHz。打板正好补上：

```
SMA ──┬──[L]──┬── AD 模块 VINA
      │       │
     [C1]    [C2]        C3 可选（模块输入端）
      │       │
     GND     GND
```

- **先按"直通"画**：L 位置焊 0 Ω，C1/C2/C3 不焊 → 与现在飞线效果一样，先跑通。
- 需要时再焊元件：截止频率按 `f = 1/(2π√(LC))` 估，
  目标 1.2~1.5 MHz（覆盖 1 MHz 通带，压掉 2 MHz 以上的混叠）。
  例：L = 4.7 µH、C = 3.3 nF → 约 1.28 MHz（二阶，-40 dB/dec）。
- ⚠️ AD9226 模块的输入阻抗**不是 50 Ω**（板载 75R/62R + AD8138，约几百欧），
  所以 LC 的实际截止点会比计算值低。**焊完要实测**（用信号源扫频看哪个频率开始掉）。
- SMA 到模块的走线按 50 Ω 微带画（如果板厚 1.6 mm、FR4，线宽约 3 mm）；
  距离很短（< 20 mm）时不做阻抗控制也能用。

### 5.2 布局顺序（从左到右）

```
[SMA] → [LC 焊盘] → [AD9226 模块] → [Nano 20K] → [HDMI 座朝板边]
                                        ↑
                          [EC11] [KEY1..5] 放在板边方便操作
                          [LED] 放在能看见的位置
```

- **AD 模块紧贴 SMA**，模拟输入走线越短越好。
- **Nano 的 HDMI 座和 USB-C 必须朝板边**，否则插不上线。
- 人机界面（编码器/按键）放在板边，手指够得着的一侧。
- 数字区（Nano 下方）与模拟区（SMA→模块）**地平面分开，单点连接**（0 Ω 或磁珠）。
- AD 的 12 根数据线尽量**等长、并行、下面有完整地**，不要跨分割。

## 6. 上电检查顺序

1. **不插 Nano、不插 AD 模块**，只上 5V：量 5V 输出、3V3（若底板自己产生）、
   各上拉电阻上是否有 3.3 V。
2. 插 Nano（USB 只连数据或按第 3 节处理供电），烧 `ad9226_hdmi_spectrum.fs`，
   接 HDMI：应看到频谱界面（此时无信号，底部一条平线）。
3. 按 KEY1 / 转编码器：Span 应在 1 MHz / 250 kHz / 50 kHz / 10 kHz 之间切换，
   顶栏文字跟着变。**这一步不需要 AD 模块**，能单独验证人机界面。
4. 插 AD 模块，SMA 接信号源（1 kHz，0.3 Vrms）：Span 10 kHz 档应看到 1/10 处的谱线。
5. 加大幅度到 OTR 灯亮，确认过载指示正常。

## 7. 打板前必须实测的三件事

| 项目 | 为什么要量 | 怎么量 |
|---|---|---|
| **Nano 两排排针的中心距** | 决定两个母座的间距，画错插不进去 | 卡尺量两排孔中心，约 20.3 mm（0.8"），**以实测为准** |
| **AD 模块 P2 的 2×10 排针位置** | 模块要能插上，且方向不能反 | 量模块上 P2 到板边的距离，并确认 1 脚标记 |
| **EC11 的 A/B/C 引脚顺序** | 各家定义不同，接错方向反或短路 | 万用表蜂鸣档，慢慢转，记录哪两个脚先通 |

外加一条：**Nano 的外形 22.55 × 54.04 mm**，母座要留出板边空间，
否则 HDMI 和 USB-C 会顶到别的东西。

### 7.1 EC11 引脚判断（30 秒，万用表蜂鸣档）

**不同厂家的 A/B/C 物理位置可能完全不同，字母不能照抄。** 但功能只有三组，
按下面顺序量一定能分清：

1. **先找按压开关（D/E）**：不转轴，只按下去，两脚之间"由不通变通"的那一对就是 D/E。
   开关没有极性，谁接 GND 都行。
2. **再找公共端（C）**：剩下 3 个脚里，两两测并慢慢转轴。
   **与另外两个脚都"交替通断"的那个脚就是 C**；另外两个脚之间**永远不通**，是 A 和 B。
3. **剩下的就是外壳 H**：和所有脚都不通、只与金属壳导通，接 GND（可选）。

实测经验：

| 现象 | 结论 |
|---|---|
| 转轴时某脚与另两脚交替通断 | 该脚 = C（公共端） |
| 两脚之间转动时"时通时断" | 这两个分别是 A、B（但互相不通） |
| 只按压才通断 | 开关 D/E |
| 与任何脚都不通 | 外壳 H |

**接错的后果**（都不会烧，都是 3.3V 弱上拉回路）：

- **A/B 接反** → 旋转方向相反，改软件或对调两根线即可
- **D/E 接反** → 无影响
- **C 接错**（接到 A 或 B 上）→ 会变成"单相"信号：转动有反应，但**方向永远一样**，
  或者干脆不动。这时把三个脚换一个当 C 再试，最多试 3 次
- **H 接 3V3** → 不要这么接，外壳只接地

> 嫌麻烦的话有个"试接法"：随便挑 3 个脚当 A/B/C 接上（C 接 GND），转轴看屏幕跨度变不变。
> 变且方向对 = 成了；方向反 = 对调 A/B；不变或方向永远一样 = C 选错了，换一个脚再试。
> 因为全是开关到地，接错不会损坏任何东西。

## 8. 若要改按键数量

10 个可用 IO 已经用满。想加按键，三条路：

1. **省 LED**：71 脚的 LED_OVR 改成第 6 个按键（过载就靠屏幕看，反正 OTR 也会让谱线变形）。
2. **编码器做组合键**：`key_enc_ctrl.v` 里有 `ENC_STEP` 参数，
   可以加"长按编码器 + 旋转"的第二功能。
3. **按键矩阵**：3 根线扫 6 个键（2×3），但需要二极管防串键，且引脚也不够。

推荐第 1 条，改动最小。
