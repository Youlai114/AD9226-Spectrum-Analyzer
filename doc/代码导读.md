## 一、系统时钟域与顶层架构（`src/video_top.v`）

本工程仅使用板载 `27.00 MHz` 晶振（`I_clk`），经片上 PLL/分频产生 3 个工作时钟：

| 时钟 | 频率 | 来源 | 主要驱动模块 |
| :--- | :--- | :--- | :--- |
| `I_clk` | `27.00 MHz` | 板载晶振 | 系统心跳计数器、PLL 输入 |
| `adc_clk` | `54.00 MHz` | `ad9226_pll` | `ad9226_capture`、`fft_ip_wrap`、`wave_capture` |
| `serial_clk` | `371.25 MHz` | `TMDS_rPLL` | `dvi_tx`（HDMI 5× 串行输出） |
| `pix_clk` | `74.25 MHz` | `CLKDIV`（÷5） | `video_timing`、`input_ctrl`、`harm_wave_synth`、`spec_display`、`ui_text_rom` |

### 跨时钟域（CDC）处理原则
1. **慢速控制参数**（`span / win / det / trc / avg`）：在 `video_top.v` 中用两级触发器从 `pix_clk` 同步到 `adc_clk`。
2. **频谱写入数据**（`O_frame_start / O_mag_en / O_mag_addr / O_mag`）：由 `spec_data_if.v` 内部双端口乒乓 RAM 完成 `adc_clk` → `pix_clk` 跨时钟缓冲。
3. **帧级测量结果**（`O_pk_col / O_pk_mag / O_pk_left / O_pk_right / O_spur_mag / O_h2..h5_*`、`O_vpp / O_period_* / O_high_smp`）：采用 **Toggle 握手**（`O_pk_tog` / `O_vpp_tog`），在 `pix_clk` 域经 3 级同步边沿检测后锁存，避免多比特亚稳态。

## 三、数据流与核心算法导读

### 1. 信号采集与频谱流水线（`adc_clk` 域）
1. **抽取与降噪（`ad9226_capture.v`）**：
   - ADC 始终以 `54 MSPS` 工作，按 `dec_sel`（`0..15`）输出采样脉冲 `adc_smp_en`。
   - `span 6`（27 MHz）直通，`span 11`（13.5 MHz）`÷2` 移位，`span 9/10`（2.7M/5.4M）浅抽取 `dec_lo`，其余档位采用均值抽取，等效采样率从 `27 MHz` 降至 `400 Hz`。
2. **去直流 + 环形缓冲 + 滑窗（`fft_ip_wrap.v`）**：
   - `dc_acc` 对输入 `I_smp` 做时间常数 4096 样点的一阶 IIR 直流追踪，写入 `cap_mem`（3 BSRAM）前减去直流偏置 `dc_acc[27:12]`。
   - 低频档（`200Hz / 500Hz / 1k / 2k`）由 `video_top.v` 控制 `hop_n = 256 / 512 / 1024 / 2048` 实现环形滑窗重叠刷新，在不牺牲 4096 点分辨率的前提下把刷新时间保持在 `0.5~0.6s`。
3. **FFT 与频谱后处理（`fft_ip_wrap.v`）**：
   - 读出 `cap_mem` 时同步查 `win_rom` 完成加窗，送入 `Gowin_FFT_Top`（4096 点）。
   - FFT 复数输出经幅值近似 + 逆 sinc 补偿（`27 MHz` 档关闭）→ 检波合并 → 指数视频平均 → 迹线保持（`CLR / MAXH / MINH / VIEW`）得到最终 1024 列显示幅度 `trc_out`。
   - `s7_vld` 扫描 `0..1023` 列时同步提取：
     - **主峰**：`s7_col >= 3` 最大值 `O_pk_col / O_pk_mag` 及左右邻 bin（`O_pk_left / O_pk_right`）；
     - **2~5 次谐波**：在 `2*O_pk_col .. 5*O_pk_col` 邻域（`±2` 列）搜峰并锁存对应复数谱 `O_h1..h5_re/im`；
     - **最大杂散**：在 `s7_col >= 3` 且剔除 `O_pk_col ± 4` 主瓣后追踪 `O_spur_mag`（用于 `SFDR`）。

### 2. 时域触发与谐波合成（`adc_clk` → `pix_clk`）
- **触发与捕获（`wave_capture.v`）**：
  - 每次 `I_tdec` 抽取（`÷1 / ÷2 / ÷4`，对应 `T-ZM` 低倍率）控制写入采样步进，在满足 `AUTO / RISE / FALL / SNGL` 条件后锁存 1024 点波形并计算 `Vpp`、过零周期 `period_smp / period_cnt` 与高电平脉宽 `high_smp`。
- **谐波重构（`harm_wave_synth.v`）**：
  - 收到 `I_pk_tog` 后顺序重构 1~5 次谐波正弦分量并存入 BSRAM，读地址直接与 `spec_display` 的 `wave_addr` 对齐，且相位步进受 `I_tdec` 同步缩放，保证在任意 `T-ZM` 档位下与原始时域波形完全同相/同周期对齐。

### 3. 6 级显示流水线与辅助计算（`spec_display.v`）
为了在 `74.25 MHz`（周期 `13.46 ns`）下零违例运行，像素渲染拆分为 6 级同步流水线：
- **Stage 0~1**：由 `px / py` 计算网格坐标 `cell_col / cell_row`，查 `ui_text_rom` 得到 ASCII 字符 `ui_char`。
- **Stage 2**：读取频谱 RAM（`mag_ram`、`peak_ram`、`ref_mem`）、波形 RAM（`wave_data`、`harm_wave`）及 `ui_font_rom` 字模点阵。
- **Stage 3**：对数变换 `log_split` + `log_row_base`、时域波形坐标映射、`lim_r3` 门限行高计算。
- **Stage 4**：`scale_row` 垂直量程缩放、折线上下包络（`lo4..hi4`）防断线处理、像素命中判定。
- **Stage 5~6**：按优先级合成最终 24-bit RGB（文字 > 光标 > 谐波标记 > 波形 > 频谱 > 余辉 > 参考迹线 > 门限线/触发线 > 网格 > 背景），`de / hs / vs` 同步延迟 6 拍输出给 `DVI_TX_Top`。

**零乘法器顺序计算引擎（`spec_display.v` 内部）**：
- **峰值格式化（`fmt_busy`）**：1/8-bin 抛物线内插（`pk_sub_q3`）、`PEAK` 频率/dBFS、`VPP`、`WF`、`DT%`。
- **辅助状态机（`aux_phase 0..14`）**：分拍复用同一组 `log_split`、`×1926`、`bcd_add3` 逻辑，顺序完成 `MARKER`、`H2..H5 dBc`、牛顿/逐次逼近开方 + 除法求 `THD%`、`H1..H5` 频率、`Delta Marker` 与 `SFDR`。
- **时域坐标与双光标状态机（`tc_st` / `tx_st`）**：当 `Span / T-ZM / Marker` 变化时计算 `T1 / dT / 1/dT` 及 `TIME` 视图 X 轴 4 等分时间刻度。
