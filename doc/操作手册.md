# FPGA 频谱分析仪操作手册（v2.0.1）

本系统基于 Gowin FPGA（`54 MHz` ADC 采样率、`4096` 点 FFT、1280×720 HDMI 输出）实现，集成了**频谱分析（SPEC）**、**时域示波（TIME）**、**分屏对比（SPLIT）**与**谐波/失真分析**功能。内部已集成 4096 点一阶 IIR 直流偏置消除（自动抑制 0 Hz 直流尖峰）。

---

## 一、按键与编码器总览

### 1. 独立按键（KEY1 ~ KEY5）

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **KEY1** | Span 循环 | 依次切换 16 档商用 1-2-5 序列扫宽：`1.00M -> 500k -> 200k -> 100k -> 50.0k -> 20.0k -> 10.0k -> 5.00k -> 2.00k -> 1.00k -> 500Hz -> 200Hz -> 27.0M -> 13.5M -> 5.40M -> 2.70M` |
| **KEY2** | 视图切换 | 循环切换显示模式：`SPEC`（全频谱）-> `SPLIT`（上频谱/下时域）-> `TIME`（全时域） |
| **KEY3** | AUTO Span | 从 `27 MHz` 全带宽逐级向下缩进，自动锁定主信号所在最佳频宽 |
| **KEY4** | 菜单开关 | 打开或关闭右侧参数菜单（菜单关闭时编码器直接调 Span） |
| **KEY5** | 窗函数切换 | 依次切换：`Hann -> Rect -> Black -> FlatTop` |

### 2. EC11 旋转编码器

- **旋转**：
  - 菜单关闭时：直接切换 `Span`。
  - 菜单打开时：调节当前高亮菜单项的参数值。
- **短按**：
  - 菜单关闭时：打开菜单。
  - 菜单打开时：在当前菜单项的子模式间切换，或进入下一菜单项。
- **长按（≥ 800 ms）**：**Preset**，一键恢复出厂默认设置（`1MHz / Hann / Pos Peak / Clear Write / Auto Avg / SPEC`）。

## 二、右侧菜单功能详解（0 ~ 9）

按 **KEY4** 或短按编码器打开菜单后，短按可按顺序切换以下 10 项参数：

### 0. Y-SCL / REF / LIMIT（垂直刻度、参考电平与门限线）
短按依次在 3 个子项间切换（前缀 `*` 表示当前正在调节的子项）：
1. `*SCL`：垂直刻度 `5 dB/div` / `2 dB/div` / `1 dB/div`。
2. `*REF`：顶部参考电平 `0 dB` / `-10 dB` / `-20 dB` / `-30 dB` / `-40 dB`。
3. `*LIMIT`：频域水平门限线，可选 `OFF` 或 `-10 dB` ~ `-80 dB`（步进 `10 dB`）。开启后频谱区绘制**红色水平虚线**，底栏同步显示 `LIM:PASS` 或 `LIM:FAIL`（主峰超过门限即告警）。

### 1. WINDOW（窗函数）
- `HANN`：汉宁窗（通用测量，兼顾频率分辨与旁瓣抑制）
- `RECT`：矩形窗（无加窗，适合相干采样或瞬态）
- `BLACK`：布莱克曼窗（高旁瓣抑制，适合大动态范围谐波/杂散测量）
- `FLATTOP`：平顶窗（幅值平坦，适合高精度幅度测量）

### 2. DETECT（检波方式）
- `POS PK`：正峰值检波（默认，保留频谱包络最大值）
- `AVG`：平均检波
- `NEG PK`：负峰值检波
- `SAMPLE`：采样检波

### 3. TRACE / REF（主迹线与参考迹线）
短按在主迹线 `*T:` 与参考迹线 `*R:` 间切换：
- `*T:CLR`：实时刷新（Clear Write）
- `*T:MAXH`：最大值保持（Max Hold）
- `*T:MINH`：最小值保持（Min Hold）
- `*T:VIEW`：冻结当前迹线（View）
- `*R:OFF / ON / CAP`：参考迹线控制。旋至 `CAP` 时将当前频谱保存至参考缓存并以浅蓝色叠加显示，方便前后波形对比。

### 4. AVG（平均次数）
- 可选：`AUTO` / `1` / `4` / `16` / `64`（`AUTO` 根据 Span 自动匹配平滑次数）。

### 5. SPAN（扫宽，16 档商用 1-2-5 序列）
- `200 Hz` ~ `1.00 MHz` 严格遵循商用仪器 `1-2-5` 步进：`200Hz / 500Hz / 1.00kHz / 2.00kHz / 5.00kHz / 10.0kHz / 20.0kHz / 50.0kHz / 100kHz / 200kHz / 500kHz / 1.00MHz`。
- 高频与全带宽：`2.70MHz / 5.40MHz / 13.5MHz / 27.0MHz`（Nyquist 全带宽）。
- **测试建议**：观察方波、脉冲波、锯齿波或微分尖峰时，若接有窄带 RC 抗混叠小板会滤除高次谐波导致方波变圆润；测量高频非正弦波时请去掉窄带 RC 小板并选用 `2.70M ~ 27.0MHz` 档位。

### 6. MARKER（频标 / 时域光标）
- **频域模式（SPEC / SPLIT）**：
  - Marker 关闭时**逆时针旋转**：一键吸峰并自动进入 `FINE` 细调模式。
  - 开启后短按编码器依次切换：
    - `COARSE`：粗调（±16 列）
    - `FINE`：细调（±1 列）
    - `DELTA`：差值频标（锁定当前点为参考标，实时显示 `D: Δf / ΔdB`）
    - `TRACK`：峰值自动追踪（紫色频标自动跟随信号主峰移动；旋转编码器即退出追踪）
- **时域模式（TIME）**：
  - 复用为时域垂直光标，配合 `DELTA` 模式测量 `T1`、`dT`（时间差）与 `1/dT`（对应频率）。

### 7. TRIG / TLVL（触发模式与触发电平）
短按在触发模式与触发电平间切换：
- 触发模式：`AUTO`（自动）/ `RISE`（上升沿）/ `FALL`（下降沿）/ `SNGL`（单次触发，捕获后自动保持）/ `HOLD`（手动暂停）。
- `*L:` 触发电平：`-50%` ~ `MID` ~ `+50%`（9 档），在时域区绘制**橙色水平虚线**。

### 8. V-SCL / T-ZM（时域垂直/水平缩放）
短按在 `*V:` 与 `*T:` 间切换：
- `*V:` 垂直缩放：`AUTO`（自动满屏适配）及 `x.25` ~ `x64` 手动倍率。在 `TIME` 视图下，左侧纵坐标自动切换为对应电压刻度（`±2.0V` ~ `±8mV`，`AUTO` 显示 `±FS / ±50% / 0V`）。
- `*T:` 水平时基缩放：`x.25` ~ `x64`（含抽取档位 `x.25 / x.5`）。在 `TIME` 视图下，底部横坐标自动随 `T-ZM` 与 `Span` 实时更新 4 等分时间刻度及单位（`us / ms / s`）。

### 9. HARM WV（时域谐波合成对比）
- `OFF`：关闭合成波形
- `H1` ~ `H5`：单独叠加显示第 1~5 次谐波重构波形
- `H1-5`：叠加显示 1~5 次谐波合成波形，对比原时域波形失真
- `ALL5`：同屏以不同颜色同时展开 H1~H5 各次谐波分量

## 三、屏幕测量参数说明

- **顶部状态栏**：
  - `PEAK`：主峰频率（支持 1/8-bin 抛物线亚 bin 内插）与峰值电平（`dBFS`）
  - `VPP`：时域峰峰值（`mV`）
  - `VIEW`：当前视图（`SPEC / SPLT / TIME`）
  - `DT%`：时域信号占空比
- **谐波测量行**：
  - `H2..H5`：2~5 次谐波相对基波的抑制度（`dBc`）
  - `THD%`：2~5 次谐波总谐波失真率
  - `WF`：时域过零测频结果
- **底部读数行**：
  - 第一行：频域显示 `MARKER` 频率/幅度（`DELTA` 时附加 `D:` 差值）；时域显示 `T1 / dT / 1/dT`；右侧开启 Limit 时显示 `LIM:PASS` 或 `LIM:FAIL`。
  - 第二行：显示 `H1..H5` 对应频率，右侧显示 `SFDR:xx.xdB`（无杂散动态范围）。

---

## 四、板载 LED 指示

- **LED[0]（STAT）**：系统运行心跳闪烁。
- **LED[1]（OVR）**：ADC 输入过载/削波指示（点亮表示输入幅值接近或超出满量程）。
